# Our Little Adventure — 모바일 청첩장

아이보리 편지와 오리지널 픽셀 SD 커플을 결합한 반응형 청첩장입니다.
예식은 **2027년 6월 12일 토요일 오전 11시 (Asia/Seoul)**로 설정되어 있습니다.

## 내용 수정

`wedding-config.js`에서 신랑·신부 이름, 날짜, 예식장, 홀, 주소, 지도 URL, 교통 안내를 수정하세요. 현재 신랑 노지성, 신부 이지연, 예식장 엘리에나 호텔 서울 강남으로 설정되어 있습니다. 홀과 층수는 확인 후 추가할 수 있습니다. 메인 사진은 사용자가 제공한 `assets/wedding-portrait.jpg`이며, 원본 비율로 표시합니다. 연락처와 계좌는 사용자가 요청한 디자인 확인용 예시이며 `example: true`로 표시합니다. 실제 정보로 바꾸고 `example: false`로 변경하면 전화·문자 링크가 활성화됩니다. 계좌 복사는 예시 상태에서도 가능합니다.

예식장 주소: 서울특별시 강남구 논현로 645. 주소 확인 출처: [강남구 관광안내 책자](https://visitgangnam.net/images/guidebooks/gangnam-guide-2025.pdf).

- 날짜를 바꾸면 달력·디데이·일정 저장이 함께 갱신됩니다.
- 링크 미리보기는 JavaScript를 실행하지 않는 서비스가 많으므로 `index.html`의 title, description, Open Graph 문구와 기본 날짜도 함께 수정하세요.
- 디자인 색상과 글꼴은 `tokens.css`에 모았습니다.
- 이름·주소 등 소스 내용은 공개 GitHub 저장소 및 Pages에서 누구나 볼 수 있습니다.

## 로컬 실행

```sh
npm run dev
```

http://127.0.0.1:4173 에서 확인합니다. Node.js 22와 Python 3가 있으면 되며 npm 설치 과정은 필요 없습니다.

```sh
npm test
npm run build
```

빌드 결과는 `dist/`입니다. 상대 경로를 사용하여 GitHub Pages 저장소 하위 경로에서도 동작합니다.

## GitHub Pages

GitHub 저장소 Settings → Pages → Source를 **GitHub Actions**로 설정합니다. `main` 브랜치에 push하면 `.github/workflows/pages.yml`이 테스트와 빌드를 거쳐 배포합니다. 사이트 파일만 배포하며 테스트 및 개발 파일은 배포하지 않습니다.

공식 안내: https://docs.github.com/en/pages/getting-started-with-github-pages/using-custom-workflows-with-github-pages

## 애니메이션

- 신랑·신부가 벽돌, 돌, 웅덩이, 화분이 등장하는 길을 계속 달립니다. 일부 장애물은 자동으로 넘고, 부딪히면 1.6초 동안 감속했다가 회복합니다.
- 화면 아래의 ‘함께 점프!’ 버튼을 누르면 차례로 점프합니다. 전역 스페이스 단축키는 사용하지 않습니다.
- 위쪽 미니맵은 예식 1년 전부터 예식 시간까지 실제 시간의 흐름을 표시합니다. 충돌이나 일시정지는 디데이에 영향을 주지 않습니다. 실제 예식 시간이 되면 식장 도착 장면으로 바뀝니다.
- 일시정지 버튼을 제공하고, 화면 밖이나 비활성 탭에서는 루프를 멈춥니다.
- 동작 줄이기 설정이 켜진 기기에서는 정지 화면으로 시작하며, 사용자가 재생할 수 있습니다.
- 캐릭터와 배경은 직접 만든 픽셀 그래픽이며 외부 게임 자산을 사용하지 않습니다.

## 사진·영상 앨범

`assets/album/`에 파일을 추가하고 `album-config.js`의 배열에 아래처럼 항목을 추가한 뒤 배포하세요. 현재는 제공받은 사진 한 장이 등록되어 있습니다. 이 공개 앨범과 하객이 두 사람에게 보내는 비공개 사진 업로드는 별개입니다.

```js
{ type: 'image', src: './assets/album/photo-02.jpg', alt: '사진 설명', caption: '함께한 날' },
{ type: 'video', src: './assets/album/film.mp4', poster: './assets/album/film-cover.jpg', caption: '우리의 영상' },
```

사진·영상을 누르면 크게 열립니다. 사진 확대, 이전·다음 버튼, 좌우 방향키, 모바일 좌우 스와이프를 지원합니다. 사진이 한 장일 때 이동 버튼은 비활성화됩니다. 영상은 자동 재생하지 않으며 이동하거나 닫으면 정지합니다. 모바일 호환성을 위해 MP4(H.264/AAC)를 권장하며 필요하면 `captions`에 한국어 WebVTT 자막 경로를 지정할 수 있습니다.

## 기타 기능

한국 시간 기준 카운트다운, 달력, ICS 일정 다운로드, 네이티브 공유 또는 링크 복사, 주소 복사 및 지도 링크를 제공합니다. 예식 시간은 사진 아래와 날짜 안내에 ‘오전 11:00’ 형식으로 표시합니다. Google Fonts 글꼴과 Google Maps 삽입 지도를 외부에서 불러옵니다. 지도 아래에는 네이버지도·카카오맵 링크도 제공합니다.

## 참여 기능과 관리 화면

- 공개 축하 방명록: 받는 사람 선택, 최근 3개/더 보기, 작성 비밀번호로 삭제, 관리자 숨김/삭제.
- 비공개 참석 응답: 신랑·신부 측, 참석/불참/미정, 본인 포함 인원, 식사 인원, 메모. 응답번호와 비밀번호로 수정.
- 비공개 하객 사진: JPG/PNG/WEBP 한 장씩 최대 8MB, 관리자만 원본 열람. 공개 앨범에 자동 게시하지 않음.
- `/admin.html`: 관리자 로그인, 참석 인원 집계, CSV 내보내기, 글 관리, 사진 열람/삭제. 로그인 토큰은 메모리에만 보관하며 만료 시 화면을 비움.

**현재 저장 서비스 연결값은 비어 있습니다.** 연결 전에는 접수 준비 안내를 표시하고 전송 버튼을 비활성화합니다. 가짜 성공 메시지나 브라우저에만 저장되는 방명록은 사용하지 않습니다. 실제 계정 연결·DB/함수 배포는 [설정 안내](BACKEND_SETUP.md)를 따르세요. GitHub Pages에는 화면 파일만 배포하며 `supabase/`, 테스트, 비밀 환경 변수는 포함하지 않습니다.

## 교통 안내

`wedding-config.js`의 `travelGuide`에서 자동차·지하철·버스·도보 안내를 수정합니다. 2026-10-22 기준 [와이즈웨딩](https://app.wisewedding.co.kr/weddinghall/weddinghall_share.asp?code=1366) 및 [라인테크시스템의 호텔 행사 교통 안내](https://linetek.co.kr/?lang=kr&mId=124&mode=view)를 교차 확인했습니다. 호텔 공식 홈페이지는 조회 시 열리지 않았습니다. 주차 무료 시간은 자료마다 달라 확정값을 게시하지 않았습니다. 예식 전 호텔 확인 후 주차 조건과 변경된 버스 노선을 갱신하세요.
